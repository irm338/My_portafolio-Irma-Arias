# Portafolio arcade — Irma Yaneht Arias García

¡Hola! Soy **Irma Yaneht Arias García**, estudiante de desarrollo de software en **Campuslands**. Este portafolio convierte mi perfil y mis proyectos en una experiencia interactiva inspirada en los videojuegos arcade y el neón.

## Experiencia interactiva

- HUD con nivel, experiencia por secciones y reproductor musical generado con Web Audio API.
- Escenario animado con partículas y una pista de velocidad dibujados en Canvas.
- Menú de navegación accesible con teclado: flechas arriba y abajo para elegir una sección y Enter para abrirla.
- Fichas de misión con filtros por categoría, detalles y enlaces a GitHub.
- Insignias del arsenal tecnológico con descripciones interactivas.
- Zona de pasiones con acelerador de moto, turbo, reto de fútbol, pista de baile y terminal de comandos.
- Minijuego **YANI TURBO RUN** con controles de teclado y táctiles; el récord se guarda en el navegador.
- Botón para copiar el correo con notificación de logro.

## Ejecutar localmente

No se requiere instalar dependencias ni usar frameworks. Abre `index.html` en un navegador o publica los archivos en GitHub Pages. La hoja de estilos, el JavaScript y la fotografía (`style.css`, `javaScript.js` y `perfil.jpg`) se cargan desde rutas relativas.

El audio empieza únicamente cuando se pulsa reproducir, como requieren los navegadores. El récord del minijuego se almacena en `localStorage` del navegador.
